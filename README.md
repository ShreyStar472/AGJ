# AGJ — App Generator Ka Jalva

**AGJ** is a beginner-friendly programming language developed by **AGJ Studio**.

AGJ is designed to make programming easier to learn through a simple syntax and an easy-to-use development environment.

## Official Website

https://agjstudio.com/

## Documentation

Learn AGJ syntax, variables, data types, operators, conditions, loops, and more:

https://agjstudio.com/AGJ-Docs.html

## Download AGJ

Get AGJ from the official download page:

https://agjstudio.com/AGJ.html

## Features

- Simple programming syntax
- Variables and data types
- Mathematical operations
- Conditional statements
- Loops
- User input and output
- GUI-based coding environment
