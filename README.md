# AGJ — App Generator Ka Jalva

**AGJ (App Generator Ka Jalva)** is an independently developed, beginner-friendly programming language created by **Shrey Radadia** under **AGJ Studio**.

AGJ is designed to make programming easier to learn through readable syntax and a simple development environment. It supports variables, data types, mathematical operations, conditional statements, loops, user input, and output.

AGJ Studio provides the official development environment, documentation, downloads, and programming resources for AGJ.

## Features

- Beginner-friendly programming syntax
- Variables and data types
- Mathematical operations
- Conditional statements
- Loops and repetition
- User input and output
- GUI-based development environment
- Visual Studio Code language support

## Visual Studio Code Extension

AGJ has an official Visual Studio Code extension that provides AGJ language support, syntax highlighting, and program-running integration.

Find it by searching for **AGJ Programming Language** in the Visual Studio Code Marketplace.
